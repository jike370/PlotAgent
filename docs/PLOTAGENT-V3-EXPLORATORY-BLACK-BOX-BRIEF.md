# PlotAgent v3 探索性黑盒功能简报

> 本文件提供给独立黑盒测试人员。它只说明用户可见功能、产品边界和正式入口，不提供测试步骤、字段绑定答案、历史缺陷或底层实现信息。

## 1. 产品是什么

PlotAgent v3 是一款 Windows 科研绘图产品。用户导入表格数据、明确选择图类，并可以用自然语言描述创建或修改目标。产品会声明其理解和字段绑定，在用户确认后生成图形。

产品同时提供两种交互方式：

- 图形库和字段映射等确定性控件；
- 面向当前数据和图形对象的自然语言 Agent。

自然语言不会绕过确认。用户确认前不应产生图形版本或修改项目。

## 2. 正式入口

- 平台：Windows 桌面版。
- 仓库根目录：`D:\plotv3`。
- 正式开发入口：`pnpm dev`。
- 只认可正式 Electron 窗口中的观察结果。

浏览器预览、静态审计页、源码、单元测试、内部接口和历史产物均不能用来替代黑盒证据。

## 3. 用户工作流

用户可以：

1. 新建、打开、重命名和管理本地项目；
2. 导入受支持的表格文件并选择数据表；
3. 从图形库明确选择图类；
4. 提交自然语言需求；
5. 查看 Agent 的理解、追问或字段/编辑确认卡；
6. 确认后创建图或形成新版本；
7. 继续修改、撤销或重做；
8. 导出 PNG、SVG 或 OPJU；
9. 关闭并重新启动产品后继续打开已有项目。

如果缺少数据或图类，用户仍可先发送自然语言。产品应说明还需要什么，但不会替用户擅自选择图类并执行。

当前正式支持 34 张单图：

| 图类 | 图类 | 图类 |

| 柱状图 | 分组柱状图 | 堆积柱状图 |
| 100% 堆积柱状图 | 列散点图 | Tukey 箱线图 |
| 小提琴图 | 直方图 | 面积图 |

| 填色等高线图 | Trellis 分面图 | Nyquist 图 |
| 混淆矩阵 | 垂线图 | 棒棒糖图 |
| 蜂群图 | 浮动柱状图 | 人口金字塔 |

| 双 Y 轴柱线图 | Y 偏移堆叠线图 | 线条序列图 |
| 前后对比图 |  |  |

图形库应以用户可理解的名称呈现。用户不需要知道内部 ID、模板名或实现方式。

## 5. 数据能力

产品面向结构化表格数据。可尝试导入：

- CSV、TSV；
- TXT、DAT 中可识别的表格数据；
- XLS、XLSX、XLSM 中受支持的工作表数据。

产品应保留可识别的文件名、工作表名和字段名。导入多个文件时，单个文件失败不应吞掉其他成功项。

原始输入应保持只读。产品可以为绘图进行确定性的表格适配或图形所需的封闭计算，但不会把这些行为伪装成任意数据分析。

## 6. Agent 能力

Agent 面向当前数据、选定图类和当前图形工作。它可以：

- 理解创建或修改目标；
- 声明字段绑定；
- 在真正缺少信息时追问；
- 生成用户可确认的绘图任务；
- 修改当前图形支持的标题、坐标轴、系列、图例和图类参数；
- 明确拒绝当前产品不支持的请求。

用户确认前无副作用。失败、取消、超时和过期响应不应留下半版本，也不应覆盖更新后的上下文。

执行期间，界面可以显示来自真实任务的阶段反馈，例如读取数据、规划动作、校验字段和调用渲染器。它不提供虚构的完成百分比或剩余时间。

## 7. 图形编辑

不同图类支持的具体编辑能力可能不同。可观察的公共范围包括：

- 图标题；
- 适用的轴标题、线性或 Log10、范围和方向；
- 适用的系列颜色、线宽、线型、符号和符号大小；
- 图例显示及适用位置；
- 图类声明支持的专属参数；
- 安全文本标注；
- 字段重新绑定；
- 撤销和重做。

不支持的编辑应被明确拒绝，而不是被近似映射为另一个属性。

## 8. 版本与恢复

- 每次确认并成功执行的修改形成可识别的新版本；
- 未确认、失败或取消的任务不形成成功版本；
- 用户可以撤销和重做当前会话中的可逆修改；
- 产品重启后，本地项目、数据身份和最近图形应能恢复；
- 干净退出后再次启动，不应受到残留写入锁阻止。

## 9. 导出与可编辑性

- PNG：正式位图导出；
- SVG：正式矢量导出；
- OPJU：在合格 Origin 环境中生成的原生可编辑项目。

合格 OPJU 应包含实际数据和原生图对象，不是嵌入的 Matplotlib 图片。用户可以在 Origin 中继续修改适用的数据或样式，保存并重新打开。

导出成功后，桌面界面应明确显示结果及文件名或路径。Origin 不可用时，产品应在打开保存对话框之前给出可操作诊断。

PlotAgent 当前不支持把用户在 Origin 中另行修改的 OPJU 再同步回产品项目。

## 10. 明确不支持

当前不支持：

- 组合图、多面板组合工作区或自由画布；
- 任意统计分析、回归、检验或拟合；
- 任意数据清洗、单元格编辑或代码执行；
- 平滑、去噪、峰识别、基线校正等开放式分析流程；
- 图像处理；
- 核密度图、Kaplan–Meier 生存曲线、森林图及其他已移除图类；
- 将外部修改后的 OPJU 回导同步到 PlotAgent。

对于不支持或已移除的请求，正确行为是明确说明边界，不生成近似图或半成品。

## 11. 独立测试任务

请测试人员基于上述功能自行设计：

- 数据文件、数据形状和边界条件；
- 操作顺序；
- 自然语言表达；
- 正常、歧义、错误、取消、超时和恢复场景；
- 图形与导出抽样策略。

不要读取回归清单、历史缺陷、源码、内部模板映射或既有测试结果后再设计用例。测试报告应区分：

- `PASS`：实际观察符合产品声明，且证据充分；
- `FAIL`：实际观察违反产品声明；
- `BLOCKED`：外部环境阻止执行；
- `UNVERIFIED`：证据不足，不能推定结论。

测试人员应保存原始截图、导出文件、运行环境、项目名、Plot ID/版本，以及重启前后的身份信息。具体测试覆盖和优先级由测试人员独立决定。

## 12. 与冻结回归的关系

本简报用于探索性黑盒，不提供测试答案。另一份冻结回归清单用于证明承诺功能没有回归：

- 探索性黑盒回答“独立测试人员还能发现什么”；
- 冻结回归回答“已经承诺和修复的能力是否仍然成立”。

两份报告必须独立产出，最后再合并判断产品是否具备发布资格。
