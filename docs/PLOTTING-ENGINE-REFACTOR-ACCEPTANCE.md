# 绘图引擎重构验收基线

> 基线：Pi Agent runtime + PlotAgent Core + 34 个单图 renderer。组合图/K25 已删除。

## 完成定义

每个正式图必须同时满足：

1. 官方帮助、本机模板、菜单/X-Function 路线有记录；
2. 数据角色、designation、动态行/列/系列规则有强类型合同；
3. Matplotlib 与 Origin 都能创建默认态和代表性编辑态；
4. Origin 使用原生 worksheet/matrix、plot/layer 和模板，不嵌入位图；
5. 保存后由全新 Origin 会话重开，数据、结构和编辑读回一致；
6. 统一视觉页由用户实际审查；
7. 正式 Windows Electron UI 完成字段映射、Agent 确认、创建、编辑和导出黑盒。

机械测试、视觉签名和黑盒必须分开记账。未执行只能标 `UNVERIFIED`，观察到产品错误才标 `FAIL`。

## 本轮必须重测

以下图形因正式契约或 renderer 在旧视觉签名后发生变化，需要当前提交上的新证据：

- 双向误差棒图；
- 人口金字塔；
- Y 偏移堆叠线图；
- 前后对比图。

此外，误差带图、面积图、日期时间折线图、相关矩阵图和蜂群图必须重跑首轮黑盒失败路径。

## Agent 与工作流门禁

- Pi 只负责通用循环；决策必须通过 Core 能力、对象、字段、权限和版本校验。
- 用户指定数据和图类后，Agent 提出字段绑定确认卡；确认前无副作用。
- 执行时显示真实阶段；完成后返回 plot ID/版本和产物；失败不得留下半版本。
- 支持撤销/重做、批量部分失败恢复、重启恢复和陈旧响应拒绝。
- 没有图类或数据时可以追问，但不得擅自创建。

## 导出门禁

- PNG、SVG 可独立打开；
- OPJU 非零、Origin 可打开、数据与图对象原生可编辑；
- 导出完成必须给出明确成功提示和产物路径；
- Origin 不可用时必须在保存对话框前给出可操作诊断。

## 发布结论

只有 34 图当前证据、Agent/工作流、三格式导出、重启和发布门禁全部关闭后，才可写“通过”。历史 35/38/43/45 图报告不得自动继承。
