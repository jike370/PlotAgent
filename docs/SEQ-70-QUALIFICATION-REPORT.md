## 3. 综合判断

当前产品已经证明两项核心资产：较宽的科研图形覆盖，以及可靠的任务状态机。尤其是批次完成、部分失败保真、失败项恢复、幂等重放和重启恢复，在自动评测中全部通过。

但“Agent 是否可靠理解用户意图”尚未达标。模型仍会把轴级指令绑定到图对象、误映射图形专属字段，并在信息不足时偶发擅自选图；桌面黑盒又暴露了科学语义、组合图反馈、数据身份、中文字体和导入可靠性问题。因此可以作为作品集演示和邀请制体验版继续迭代，但不应宣称已达到完整正式发布标准。

## 4. 建议修复顺序

1. **Agent 语义门禁**：轴、系列、图、批次、组合图必须使用类型化对象绑定；图形专属字段角色在执行前强校验；信息不足时禁止自动选图。
2. **科学正确性**：优先修复 S07、S61、K20，再处理 K08、X03、X39、X40 的布局和可读标签。
3. **组合图闭环**：K25 成功必须返回组合图 ID/版本和结果条；失败必须给明确原因，不允许静默失败。
4. **数据可识别与导入可靠性**：显示“文件名 > 工作表名”，导入任务排队；确认态提供候选表头、分隔符和预览。
5. **桌面 Agent 体验**：区分本地 Core、在线模型配置和远程健康状态；增加可取消/重试的超时反馈，并清理陈旧错误。
6. **国际化与发布环境**：补 CJK 字体回退；在固定端口或正式打包环境重测项目持久化和 OPJU 检测。

完成 1—3 后应原样重跑冻结的 24×3 自动任务；完成 2—6 后重跑同一黑盒清单。不得修改任务、门槛或数据来换取通过。
