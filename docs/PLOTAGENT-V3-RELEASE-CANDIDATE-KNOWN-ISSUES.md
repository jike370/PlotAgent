## RC-UI-001：Agent 补充信息回复重复显示

- 状态：OPEN（仅记录，暂不修复）
- 首次记录：2026-08-20
- 观察提交：`d8c66fb9d5cdde6ec4d0bc1183366be374e2b943`
- 范围：Windows Electron 对话区 / Agent 消息呈现
- 现象：Agent 请求用户补充图类或其他必要信息时，同一段回复在同一消息区域连续显示两遍；两份内容的颜色样式不同，但语义相同。
- 期望：一次 Agent 回复只呈现一份用户可读正文；状态提示、结构化卡片与正文可以并列，但不得重复正文。
- 当前影响：造成明显的界面冗余和用户困惑；当前未观察到重复执行、重复提交或项目版本增加。
- 处理决定：当前只登记，不在本节点修改实现。进入前端样式与组件迭代时统一定位并修复，修复后补消息投影单测和正式 Electron 定向复测。
- 发布口径：若最终发布候选仍可复现，应作为 UI 产品缺陷进入黑盒结果，不得以“已记录”替代修复或验收判定。

## RC-UI-002：编辑请求的 Agent 气泡出现在已有图形上方

- 状态：IMPLEMENTED（组件回归通过，待正式 Electron 定向复核）
- 首次记录：2026-08-20
- 观察提交：`ee5c3b2a6f3bdfb467b0efcc87543f46f095aa48`
- 范围：Windows Electron 对话区 / 图形产物与消息时序投影
- 现象：当用户对已生成图形发出修改请求后，新的 Agent 回复气泡被插入到已有图形上方，与实际交互时序不一致。
- 期望：用户请求、Agent 阶段反馈、确认卡、执行结果和新图版本按产生顺序追加；已有图形不应导致后续消息倒序。
- 当前影响：用户容易误判 Agent 回复属于上一轮或图形生成前的过程；尚未观察到由此导致图形版本错误。
- 完成记录：当前图形不再固定投影到时间线末尾；后续用户消息、Agent 阶段、确认卡和导出结果都追加在现有图形之后，并已补“已有图形后再编辑”的组件回归。正式 Electron 仍需定向复核真实滚动与焦点位置。

## RC-UI-003：导出完成反馈不明显

- 状态：IMPLEMENTED（桌面边界与组件回归通过，待正式 Electron 定向复核）
- 首次记录：2026-08-20
- 范围：Windows Electron 对话区 / PNG、SVG、OPJU 导出
- 现象：导出完成后只有弱提示，用户难以确认文件是否写出，也无法从结果直接打开文件或所在文件夹。
- 完成记录：导出成功现在同时显示短时提示与持久结果条，展示文件名、大小和可用的内容哈希，并提供打开文件/打开所在文件夹。页面只提交随机资源 ID，由主进程解析受信任的导出资源；不向页面泄漏绝对路径。

## RC-EDIT-001：公共编辑缺少可见性控制

- 状态：IMPLEMENTED（确定性门禁通过，待正式 UI/Origin 黑盒复核）
- 首次记录：2026-08-20
- 观察提交：`ee5c3b2a6f3bdfb467b0efcc87543f46f095aa48`
- 范围：Agent 公共编辑动作 / Matplotlib 与 Origin 共同轴能力
- 现象：`set_axis` 已支持轴标题、尺度、范围、反转、主次刻度间隔、标签格式/旋转/字体和网格，但不能显式控制刻度标签、刻度线、轴线或轴标题的可见性；系列也缺少显示/隐藏动作。
- 已确认范围：针对 X、Y 或两轴分别控制刻度数值标签、主刻度线、次刻度线、轴线和轴标题的可见性，支持刻度线方向（向内、向外、内外两侧），并支持整个系列的显示/隐藏。各字段必须独立，不得隐式联动其他对象。
- Agent 边界：不建立“某个固定句子必然翻译为某组布尔值”的关键词/正则路由。Agent 结合当前图形对象和上下文解读意图，再输出精确的强类型可见性参数；只有实质歧义会影响结果时才追问。
- 本轮明确不扩展：刻度线长度、四侧轴框逐边控制、任意图层顺序和复杂 Origin 专属轴设置。
- 本轮不补：恢复自动/模板默认值、修改/删除已有标注、参考线生命周期。
- 实施边界：只开放 Matplotlib 和 Origin 都能稳定表达并读回的布尔能力；不用设置字号为 0、透明色或空格式字符伪装隐藏。
- 完成记录：公共合同、Agent 草案合同、34 图能力目录、Matplotlib/Origin 执行与 Origin fresh-reopen 读回、聚焦编辑器、状态累计、撤销/重做和生成 schema 已贯通；未引入自然语言正则路由。
