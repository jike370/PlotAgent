# PlotAgent 发布候选已知问题

> 本文件只保留当前仍未关闭的问题。已经实现但待回归的事项进入测试矩阵，不继续占用 known issues；历史问题从 Git 追溯。

## RC-UI-001：Agent 补充信息回复重复显示

- 状态：OPEN
- 首次记录：2026-08-20
- 范围：Windows Electron 对话区 / Agent 消息投影
- 现象：Agent 请求用户补充必要信息时，同一段正文可能在一条消息区域连续显示两份，样式不同但语义相同。
- 影响：造成明显冗余和用户困惑；尚未观察到重复执行或重复版本。
- 关闭条件：消息投影只展示一份正文；状态、结构化卡片与正文可并列但不得重复；补组件测试和正式 Electron 定向复测。

## RC-UI-002：部分中文全角括号显示为方框

- 状态：OPEN
- 首次记录：2026-08-20
- 范围：Windows Electron 对话与任务结果文字
- 现象：部分中文全角括号在产品界面中显示为缺字方框。
- 影响：不改变任务和图形结果，但降低可读性，不得写成 CJK 显示已完整通过。
- 关闭条件：定位实际字体回退链；在正式 Electron 中覆盖消息、确认卡、错误和结果文字的中英文括号；不得通过替换用户文本规避字体问题。
