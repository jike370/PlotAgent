- OPJU 原生可编辑性；
- 产品 FAIL、环境 BLOCKED、证据不足 UNVERIFIED；
- 总体 GO/NO-GO。

GO 门槛：

1. 合并后的 83 个用例全部实际执行并有充分证据；
2. 34 图全部 PASS；
3. AG-04～07、AG-11～12、VER-01～04、EXP-03～08 无 FAIL 或 UNVERIFIED；
4. 产品 FAIL=0、环境 BLOCKED=0、UNVERIFIED=0；

6. DP-01～12 全部 PASS；自动 Recipe 误匹配、候选未确认即发布、旧图数据漂移均为 0。

任何一项不满足，整体判定 NO-GO，并保留逐项事实；不得用源码、自动测试、既有视觉审查或口头观察提升黑盒判定。
