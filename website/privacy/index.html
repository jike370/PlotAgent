隐私说明

这份说明适用于 fig-agent 官网、下载页和测试反馈表单。数据处理方式发生变化时，本页会同步更新。

官网访问统计

官网计划使用 Vercel Web Analytics 统计匿名页面访问量，用于了解页面和下载入口的使用情况。该功能不使用 Cookie，也不用于建立个人画像。

下载记录

安装包发布后，下载文件将托管在腾讯云对象存储。云服务商可能为网络传输、安全和计费处理基本请求信息。fig-agent 不会在官网公开这些记录，也不会出售下载数据。

电子邮件

当你主动发送邮件时，我会收到你的邮箱地址和邮件内容，仅用于回复咨询、处理测试反馈或排查问题。请不要在邮件中发送密码、密钥或与问题无关的敏感数据。

测试反馈

当你主动提交反馈时，表单会保存产品版本、问题类型、发生环节、Windows 与 Origin 版本、模型服务、问题描述，以及你自愿填写的诊断 ID 和联系方式。反馈保存在 Vercel Blob 香港区域的私有存储中，仅用于复现、修复和回复问题；Vercel 可能为网络传输、安全和服务运行处理基本请求信息。

表单不会读取或上传项目文件、原始数据、运行日志、提示词、API Key 或模型请求正文。请不要在描述中主动填写这些内容。反馈处理完成后会删除，最长保留 180 天；你也可以通过邮件申请删除。
