不会配置模型服务，怎么办？

fig-agent 内置智谱开放平台、DeepSeek 和阿里云百炼的配置项。选择服务和模型后，填写该平台提供的 API Key 即可；自定义服务还需要填写 Base URL 和模型 ID。正式测试版会提供逐步配置说明。

不配置模型服务可以使用吗？

可以导入数据、选择图类，并执行不依赖自然语言的既定流程。使用自然语言描述绘图和修改要求时，需要先配置可用的模型服务。

需要安装哪个版本的 Origin？

OriginLab 官方的 originpro Python 包要求本机安装 Origin 2021 或更高版本，因此 2021 版起具备当前调用路径所需的基础能力。fig-agent 目前只以 OriginPro 2024 作为 OPJU 导出的测试基线；2021—2023 版本尚未完成兼容性验证。PNG 和 SVG 导出不依赖 Origin。

OriginLab Python 调用说明
没有 Origin，或者只有学习版，能使用吗？

没有安装 Origin 也可以生成并导出 PNG 和 SVG。原生 OPJU 导出需要本机安装并授权可用的 OriginPro 2024。学习版是否支持所需的自动化接口尚未完成验证，因此暂不承诺 OPJU 导出可用。

fig-agent 会把数据上传到哪里？

项目文件、图表版本和导出结果保存在本机。使用自然语言任务时，指令、字段元数据和受控样本会发送到选择的模型服务；数据保留规则由该服务决定。

支持哪些系统和数据文件？

当前测试基线是 Windows 11 x64。支持 CSV、TSV、TXT、DAT、XLS、XLSX 和 XLSM。

测试版需要付费吗？

fig-agent 测试版免费。模型服务和 Origin 由第三方提供，是否收费取决于选择的服务和授权。
