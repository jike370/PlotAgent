不会配置模型服务，怎么办？

fig-agent 内置智谱开放平台、DeepSeek 和阿里云百炼的配置项。选择服务和模型后，填写该平台提供的 API Key 即可；自定义服务还需要填写 Base URL 和模型 ID。正式测试版会提供逐步配置说明。

浏览器提示“通常不会下载此文件”，怎么办？

当前测试版尚未进行代码签名，Microsoft Edge 可能会先阻止下载。确认下载地址来自官网下载页后，在下载列表中点击安装包右侧的“…”并选择“保留”；随后点击“删除”右侧的下拉箭头，再选择“仍然保留”。文件保留后，可以核对下载页列出的 SHA-256，再点击“打开文件”启动安装程序。如果安全软件明确报告了病毒或其他威胁，请不要关闭系统防护，改为提交测试反馈并附上提示截图。

不配置模型服务可以使用吗？

可以导入数据、选择图类，并执行不依赖自然语言的既定流程。使用自然语言描述绘图和修改要求时，需要先配置可用的模型服务。

需要安装哪个版本的 Origin？

fig-agent 明确支持 OriginPro 2024 SR1（10.1.0.178）；理论上兼容 OriginPro 2024 SR0 和标准版 Origin 2024，但尚未完成完整验证。其他版本的兼容将在后续开放。

需要另外安装 Python 吗？

不需要。Windows 安装包已包含 fig-agent 运行所需的 Python 环境和 Origin 连接组件，普通用户无需安装 Python、配置环境变量或安装 originpro 包。

fig-agent 会把数据上传到哪里？

项目文件、图表版本和导出结果保存在本机。使用自然语言任务时，指令、字段元数据和受控样本会发送到选择的模型服务；数据保留规则由该服务决定。

支持哪些系统和数据文件？

当前测试基线是 Windows 11 x64。支持 CSV、TSV、TXT、DAT、XLS、XLSX 和 XLSM。

测试版需要付费吗？

fig-agent 测试版免费。模型服务和 Origin 由第三方提供，是否收费取决于选择的服务和授权。
